## Approach

I used Python's built-in `sum()` function to calculate the total of all elements in the array.

1. Pass the array to `sum()`.
2. Return the calculated sum.

## My Solution

```python id="h7k2qm"
class Solution:
    def arraySum(self, arr):
        # code here
        return sum(arr)
```

## Complexity

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(1)`
